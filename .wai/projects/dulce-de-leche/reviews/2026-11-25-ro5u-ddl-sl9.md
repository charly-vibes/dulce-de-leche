# RO5U review — DDL-sl9 (armed pre-commit pretender gate)

Diff under review: `src/gates/lefthook.rs`, `src/gates/tests.rs`, `tests/gates_command.rs`, `CHANGELOG.md`.

## Stage 1 — DRAFT (shape/scope)

Sound. The change sits in the right layer (two constants that everything else derives from:
`GateCommands::default` → `DEFAULT_PRETENDER_GATE` → `render_pre_commit_block`), tests move in
lockstep, no behavior expansion beyond the gate command itself.

Blast radius is inherently fleet-wide because the managed block is written into every consumer
repo's `lefthook.yml`.

**Scope note:** consumer repos adopt the armed gate only when they re-run `ddl init --gates`.
Verified this self-heals: `src/gates/detect.rs:125-137` compares the on-disk managed span against
the *current* rendering, so a repo still carrying `--diff-only` is reported as drifted
("managed block has drifted from the configured gate commands — run `ddl init --gates`") and
repaired on the next init. Repos that deliberately override via `.ddl/config.toml`
`gates.pretender_gate` are unaffected, because the expected rendering uses the override.

## Stage 2 — CORRECTNESS

No defects found.

- `pretender check --help` lists `--staged` ("Only check git-staged files, mutually exclusive with
  `--diff-only`"), so the old flag cannot silently linger and there is no fallback path.
- Non-git directory: **both** `--staged` and `--diff-only` exit 1 ("failed to open git repository"),
  so this is not a regression; git hooks only execute inside a git repo.
- `git commit -a` stages tracked modifications before the hook runs → staged set is non-empty.
- `git commit` with nothing staged → empty staged set → exit 0 (nothing to gate).
- Partial staging (`git add -p`) checks the staged files, matching the DDL-3fd intent (a commit that
  does not touch files carrying pre-existing violations is not blocked).
- Empirically reproduced in a throwaway repo: a 62-line staged function exits 1 and names
  `./probe.rs` under `--staged`.

## Stage 3 — CLARITY

Good. The rationale now lives at both definition sites (`PRE_COMMIT_BLOCK` and
`DEFAULT_PRETENDER_GATE` doc comments), plus a dedicated test whose doc comment explains the
failure mode, and `CHANGELOG` Unreleased/Changed carries the user-visible entry with the config
override path.

## Stage 4 — EDGE CASES

- (a) Consumer repos with the old block: drift detected and repaired (Stage 1).
- (b) Repos pinning an older ddl: unaffected.
- (c) pretender not installed: the hook command fails and lefthook blocks — identical to the
  pre-fix behaviour, since `--diff-only` also required pretender.
- (d) Repo with no staged files: exit 0.
- (e) Repo whose managed block was hand-edited: already reported as drift by the existing detector;
  unchanged.

## Stage 5 — EXCELLENCE

One gap worth closing outside this diff: an integration test executing the real hook command in a
temp git repo would need the pretender binary and is unsuitable for the unit suite. The
string-level contract plus the manual probe is the right altitude.

## Findings

**Critical:** none.
**High:** none.

### Medium — `src/gates/lefthook.rs:30` (fleet rollout untracked)

- **Evidence:** the armed gate reaches consumer repos only via `ddl init --gates`; every
  ddl-wired repo still carries the disarmed `--diff-only` block until it re-runs init.
- **Concrete fix:** file a beads ticket for the fleet rollout so it is tracked rather than
  silently dropped — e.g. "fleet: re-run `ddl init --gates` so every ddl-wired repo adopts the
  armed pre-commit gate (DDL-sl9)".

### Low — `tests/gates_command.rs:78-81` (rationale regression)

- **Evidence:** the rewritten comment cites DDL-sl9 only; the DDL-3fd rationale the original
  comment carried ("repo-wide mode fails commits touching untouched files that carry pre-existing
  violations") was dropped at the very assertion it governs and now survives only in the doc
  comment of a different test file.
- **Concrete fix:** keep a one-line DDL-3fd pointer in the assertion comment so the reason
  `--staged` preserves DDL-3fd's intent stays discoverable next to the assertion.

## Final verdict

Ship after fixing the two findings above. No Critical, no High, 1 Medium, 1 Low.
